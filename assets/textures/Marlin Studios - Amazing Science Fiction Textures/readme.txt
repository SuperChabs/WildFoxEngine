SO, HOW DO I USE THIS CD?

	For your convenience, we've provided 12 Graphic Index Pages with thumbnails of all textures, arranged according to the categories in the index (hulls, antennas, planet maps, etc.). Note that these are easily printable for your convenience, in both JPG and CMYK formats. As you'll notice, there are three sizes for each texture, and a fourth Extra Large size for the backgrounds. The thumbnails list the Large versions, for sake of convenience. These thumbnails are also representative of the Extra Large, Medium and Small versions.
	Some notes about our file naming:


FILE NAMING CONVENTIONS
Limited to eight characters, for compatibility on all platforms. 

A. First four characters -- lower-case alphabetic description of the texture.  Examples: "antn" for Antenna Array, "edhu" for Extremely Damaged Hull, etc. 
B. Characters five and six -- numeric representation of the texture in its class.  For example, "antn01, antn02, etc." 
C. Character seven -- This is either an upper case XL, L, M or S for large, medium or small resolution.  The reason for uppercase is so the "L" doesn't look like the number "one."  Example: "antn01S, edhu05L, etc."
D. Character eight -- For textures, this is blank.  For bump maps, a lower case "b" is added.   For example, an Antenna Array texture is "antn04M.tga" and the corresponding bump map is  "antn04Mb.jpg"
E. Extension -- "jpg" or "tga" in lower case (see "TGA vs. JPG," below, for more details)

	We suggest you go to the thumbnail files, and pick out a texture. Note its file name (e.g., hull05L.jpg), then go to the Textures folder and use it as you will. If you'd like to use a bump (elevation) map for that texture, go to the Bumpmaps folder (another logical place) and pick out the corresponding filename, which ends with a "b" (for Bump). For example, to find a bump map for hull05L.jpg, go to the Bumpmaps folder, then the LARGE folder and pick hull05Lb.jpg.
	An alternate and interesting way to view the textures and bumps together is to create a simple scene in your 3D program. Some artists prefer creating something as simple as a cube or a sphere. I prefer making a wall, a floor, and maybe a few simple objects like a tall cylinder or a vase. Then experiment by applying various textures and their bump maps to these meshes.


TGA vs. JPG
Sounds like a WWF Heavyweight round, doesn't it: Targa Man vs. Jay Peg? On this CD-Rom, many textures have a TGA extension instead of the more common JPG format. This is because the TGA files contain a fourth channel, making them 32-bit, rather than 24-bit files. This extra channel contains transparency information, making then alpha channel transparency maps. Read more about these below.


ALPHA CHANNEL TRANSPARENCY MAPS (TGA FILES)
	As stated above, many of the textures on this CD-Rom contain transparency. More specifically, they are:
	 antn - Antenna Arrays
	 dish - Dishes
	 edhu - Extremely Damaged Hulls
	 prtl - Portholes
	 strc - Structures
	
	All of the above files contain transparent areas, which are stored in the fourth (or alpha) channel. Different 3D programs handle transparency in different ways, so consult your program's documentation for proper use. It may even be necessary to edit your alpha channel images to avoid "haloing" or other artifacts around the textures. This procedure is beyond the scope of this document. But before you go to this extreme, make sure you've got all your program's proper switches, bells and whistles turned on - the ones that maximize the image quality of these types of textures. Once again, consult your program's documentation.


UV MAPPING AND SUNGLASSES  

	Don't confuse your sunglasses' UV rating with UV mapping in 3D programs! Different 3D programs apply textures in different ways -- it seems every program does it slightly differently. Consult your program's documentation and, if you're not already a pro, learn the art of  UV mapping. Also become familiar with the various UV mapping techniques: planar, cylindrical, spherical, cubic, etc. As a rule, "U" refers to horizontal mapping and "V" refers to vertical mapping.  UV Repeats tell you how many times a texture will be repeated over a surface, and UV Offset allows you to adjust the horizontal or vertical placement. Amplitude or Altitude defines the difference between the high points and low points of a bump map. And, if you want to be really cool, go ahead and wear your sunglasses while you do your UV mapping!


TIPS, TRICKERY AND OTHER BLACK MAGIC

	Some tips on using textures: try using various textures in places where you wouldn't ordinary think to use them. For example, many of the Hull textures have such unique patterns that they could be mapped onto a variety of non-Sci-Fi meshes. Also, try layering the textures at different opacity settings. You can achieve endless unique effects by layering multiple textures.  You can achieve this in you 3D program (if it includes texture layering) or by layering the textures in Photoshop and saving a new textures (remember, that texture is still a derivative of Marlin Studios textures, so it's not yours to freely sell or distribute). Examine your 3D scenes: use the textures as alternatives to solid colors -- while you're at it, don't forget the bump maps for the added 3D effect.  
	Some tips on using bump maps: try experimenting with various bump maps, using no texture. Or, try mixing various textures with various bump maps. The results can be startling. The collection of bump maps on this CD by itself can be a remarkable tool. Note that each 3D program handles bump maps differently. We've supplied bump maps with a nominal contrast level that is useful in most programs. If this level is too bright or dark for your particular 3D program, feel free to jack up the brightness or dim the darkness in your favorite 2D program.
